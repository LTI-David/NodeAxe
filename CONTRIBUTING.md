# Contributing to NodeAxe

Thank you for your interest in open Bitcoin infrastructure.

## Before contributing

This repository currently documents the project. The production software has not yet been released here. Please open an issue describing a proposed improvement before substantial development.

## Workflow

1. Discuss the proposed change in an issue.
2. Work on a feature branch.
3. Open a pull request explaining the change, risks, and how it was tested.
4. Never include private keys, passwords, wallet seed material, or internal host details.
5. Obtain review before merging; do not deploy code from a pull request to production automatically.

Third-party contributions must respect the licenses of upstream software and hardware designs.
